## 📦 1. Quy trình Biên dịch PyInstaller

Ứng dụng được đóng gói thành tệp thực thi độc lập `.exe` thông qua tập lệnh [build_exe.py](file:///d:/Projects/ultimate-multi-platform-download-manager/build_exe.py).

### Cấu hình tham số PyInstaller
```python
args = [
    'run.py',
    '--noconfirm',
    '--onefile',                                                     # Đóng gói thành 1 tệp duy nhất
    '--windowed',                                                    # Ẩn cửa sổ console khi chạy GUI
    f'--add-data={customtkinter_path}{os.pathsep}customtkinter',     # Asset giao diện
    '--add-data=node.exe;.',                                         # Node.exe để yt-dlp giải mã chữ ký YouTube
    '--name=Ultimate_Download_Manager'
]
```

### Xử lý môi trường đóng băng (sys.frozen)
Khi chạy ở dạng file `.exe` đã đóng gói, các file tài nguyên đi kèm (như `node.exe` hay giao diện `customtkinter`) sẽ được giải nén tạm thời vào thư mục `sys._MEIPASS`.
Hệ thống tự động chèn đường dẫn này vào đầu biến môi trường hệ thống:
```python
if getattr(sys, 'frozen', False):
    sys_path = sys._MEIPASS
    os.environ['PATH'] = sys_path + os.pathsep + os.environ['PATH']
```

## 🔄 2. Cơ chế Tự cập nhật động `yt-dlp`

Do `yt-dlp` thường xuyên phải cập nhật để vượt qua các thuật toán thay đổi liên tục của YouTube/Facebook, trong khi file `.exe` đã biên dịch thì không thể thay đổi mã nguồn trực tiếp. Ứng dụng giải quyết bằng giải pháp nạp động thư viện (Dynamic Library Injection):

### Quy trình tự động cập nhật
```
[ Khởi động ứng dụng ]
         |
         v
[ Quét updates/yt-dlp_lib/yt_dlp ] ---> Có? ---> [ Nạp đầu sys.path ]
         |                                                 |
       Không                                               v
         |                                        [ Sử dụng bản cập nhật mới ]
         v                                                 |
[ Sử dụng bản đóng gói sẵn trong .exe ]                    |
         |                                                 v
         +<------------------------------------------------+
         |
         v
[ Chạy nền kiểm tra phiên bản mới trên PyPI ]
         |
    Bản mới hơn?
         |
       Có ---> [ Tải file Wheel .whl ] ---> [ Giải nén thư mục yt_dlp vào updates/yt-dlp_lib ]
```

### Triển khai mã nguồn nạp động ([run.py](file:///d:/Projects/ultimate-multi-platform-download-manager/run.py))
```python
def apply_ytdlp_update():
    update_path = os.path.abspath("updates/yt-dlp_lib")
    if os.path.exists(update_path):
        if update_path not in sys.path:
            sys.path.insert(0, update_path)
```
* **Lợi ích**: Giúp phần mềm luôn hoạt động ổn định và vượt qua cơ chế chặn của các nền tảng video mà người dùng không cần tải lại file cài đặt `.exe` mới từ lập trình viên.
