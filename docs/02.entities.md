# Đặc tả Lược đồ Dữ liệu (Entity & Schema Specifications)

Tập tin này định nghĩa các thực thể dữ liệu được sử dụng trong hệ thống, bao gồm Lược đồ Cơ sở dữ liệu Lịch sử (SQLite) và cấu trúc Cài đặt (Settings JSON).

---

## 💾 1. SQLite Database Schema (Lịch sử tải về)

Dữ liệu lịch sử tải về được lưu trữ tập trung tại file cơ sở dữ liệu `download_history.db`.

### Bảng `downloads`
Bảng này lưu lại lịch sử mỗi lượt tải và trích xuất để hiển thị lên giao diện tab Lịch sử.

| Trường (Column) | Kiểu dữ liệu | Ràng buộc | Mô tả |
| :--- | :--- | :--- | :--- |
| `id` | `INTEGER` | `PRIMARY KEY AUTOINCREMENT` | Khóa chính tự tăng. |
| `title` | `TEXT` | `NOT NULL` | Tiêu đề video sau khi đã được làm sạch. |
| `url` | `TEXT` | | Đường dẫn gốc của video tải xuống (YouTube link, Facebook link...). |
| `platform` | `TEXT` | | Nền tảng phát hiện (youtube, tiktok, facebook, local...). |
| `status` | `TEXT` | | Trạng thái cuối cùng (`completed`, `failed`). |
| `timestamp` | `DATETIME` | `DEFAULT CURRENT_TIMESTAMP` | Thời điểm thực hiện tải. |
| `file_path` | `TEXT` | | Đường dẫn tương đối/tuyệt đối đến tệp phụ đề hoặc tệp video đã tải. |

### Câu lệnh khởi tạo bảng (SQL DDL)
```sql
CREATE TABLE IF NOT EXISTS downloads (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    url TEXT,
    platform TEXT,
    status TEXT,
    timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
    file_path TEXT
);
```

## ⚙️ 2. Settings JSON Schema (Cấu hình ứng dụng)

Cấu hình ứng dụng được lưu trữ dưới dạng JSON tại file `settings.json`.

### Các tham số cấu hình chính
```json
{
  "save_dir": "downloads",                // Thư mục lưu file video tải về
  "txt_dir": "downloads/txt_convert",     // Thư mục lưu file transcript .txt
  "whisper_model": "base",                // Model Whisper chạy local (tiny/base/small/medium/large)
  "whisper_device": "auto",               // Thiết bị chạy Whisper (auto/cpu/cuda)
  "browser_cookies": "Không dùng",        // Đọc cookies trình duyệt (Không dùng/Chrome/Edge/Firefox)
  "gemini_api_key": "",                   // Khóa API Google AI Studio cho Gemini
  "openai_api_key": "",                   // Khóa API OpenAI
  "use_cloud_api": false,                 // Bật/Tắt chế độ dịch thuật qua Cloud API
  "ai_priority": ["Gemini", "OpenAI"]    // Thứ tự ưu tiên gọi API khi phân tách người nói
}
```
* **Lưu ý**: Khóa API được lưu trực tiếp dưới dạng clear text tại file cài đặt của người dùng. Cần khuyến cáo người dùng không chia sẻ file `settings.json` này ra ngoài.
